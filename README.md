# Cadastro de Usuários

Projeto React + Vite para cadastro de usuários, utilizando Material UI.

## Instalação

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

## Build para produção

```bash
npm run build
```

Os arquivos finais ficarão na pasta `dist`.

## Deploy no GitHub Pages

1. Configure o arquivo `vite.config.js` com o base correto:
   ```js
   export default defineConfig({
     base: '/project_two_web/',
     // ...outras configs
   })
   ```
2. Execute:
   ```bash
   npm run build
   npm run deploy
   ```
3. Acesse:  
   [https://tavinsx.github.io/project_two_web/](https://tavinsx.github.io/project_two_web/)
